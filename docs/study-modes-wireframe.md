# StudyMeta 계획 · 학습 · 정리 모드 — 텍스트 와이어프레임 (초안 v0.1)

> 화면정의서 작성용 초안. 레이아웃은 텍스트 박스로만 표현하고, 각 화면마다
> 목적 / 진입·이탈 / 구성 요소 / 데이터(MCP·Evidence) / 예외를 붙였다.

---

## 0. 전제

| 항목 | 결정 |
|---|---|
| 학습이 일어나는 곳 | **AI 채팅 안** (Claude / ChatGPT + StudyMeta MCP) |
| 과목별 현황 | **홈** 화면에 둔다 |
| 근거 화면(State/Evidence 표시) | **학생용** — 내부 id·원시 점수 없이 학생 라벨로 표시 |

### 표면(Surface) 구분

| 표면 | 담당 화면 | 비고 |
|---|---|---|
| **웹** (StudyMeta 사이트) | 홈, 계획모드(입력·체크리스트), 정리 노트 열람, 근거 화면 | PDF 업로드·체크리스트 편집처럼 입력이 많은 작업 |
| **AI 채팅** (MCP) | 학습모드 전체, 정리모드(대화형 정리 + 이해 체크) | 현재 MCP는 커스텀 UI 없음 → **텍스트 응답 기준**으로 설계, 위젯은 선택 사항으로 표기 |

### 전체 흐름

```
[웹] 홈 ──▶ [웹] 계획모드 ──▶ 체크리스트 생성
  ▲                               │
  │                               ▼  "AI에서 학습 시작" (시작 문구 복사 / 딥링크)
  │                        [채팅] 학습모드
  │                          L-01 학습 시작
  │                          L-02 범위 선택  ◀── 체크리스트 상시 열람
  │                          L-03 학습 진행  (문제마다 Evidence 기록)
  │                          L-04 마무리 감지
  │                               │
  │                               ▼
  │                        [채팅] 정리모드
  │                          S-01 구조화 정리
  │                          S-02 이해 체크
  │                               │  정리 노트 저장
  │                               ▼
  └────────────────────── [웹] S-03 근거 화면 / 정리 노트
                           (결과가 홈·체크리스트에 반영 → 다음 계획으로 순환)
```

### 화면 ID

| ID | 화면 | 표면 |
|---|---|---|
| H-01 | 홈 (과목별 현황) | 웹 |
| P-01 | 과목 등록 | 웹 |
| P-02 | 시험 일정 · 시험범위 | 웹 |
| P-03 | 자료(PDF) 업로드 | 웹 |
| P-04 | 분석 중 | 웹 |
| P-05 | 할 일 체크리스트 | 웹 (+ 채팅에서 열람) |
| L-01 | 학습 시작 | 채팅 |
| L-02 | 학습 범위 선택 | 채팅 |
| L-03 | 학습 진행 | 채팅 |
| L-04 | 학습 마무리 감지 | 채팅 |
| S-01 | 구조화 정리 | 채팅 (→ 웹 정리 노트에 저장) |
| S-02 | 이해 체크 | 채팅 |
| S-03 | 근거 화면 (State · Evidence · 도움 횟수) | 웹 (채팅엔 요약본) |

## 1. 홈

### H-01 홈 (과목별 현황)

- **목적**: 로그인 직후 "지금 무엇을 해야 하는지"와 과목별 상태를 한 번에 본다.
- **진입**: 로그인 / 채팅에서 "웹에서 보기" 링크 / 정리 완료 후
- **이탈**: 계획모드(P-01·P-05), 채팅으로 학습 시작, 근거 화면(S-03)

```
┌─ 상단 ───────────────────────────────────────
│ StudyMeta                         [내 정보]
├─ 과목 탭 ────────────────────────────────────
│ [미적분학 ●] [화학] [경제학원론] [+ 과목 추가]
├─ 과목 요약 ──────────────────────────────────
│ 미적분학 · 중간고사 D-12 (범위: 1~4단원)
│ "예상한 것과 실제 결과가 꽤 잘 맞고 있어요"
│ [계획 보기/수정]
├─ 오늘 할 일 (체크리스트에서 오늘 배정분) ─────────
│ ☐ 연쇄법칙 복습            [AI] 복습 추천
│ ☐ 극한의 정의 개념 확인      [AI] 확인 필요
│ ☑ 2단원 예제 풀기          [나]
│
│ [ AI에서 학습 시작 → ]   ← 시작 문구 복사 + Claude/ChatGPT 열기
├─ 스킬 카드 ───────────────────────────────────
│ ┌ 연쇄법칙 ─────────────   ┌ 극한의 정의 ─────────
│ │ 풀이 과정이 능숙해지고     │ 헷갈리는 부분이 있는 것
│ │ 있어요                  │ 같아요
│ │ [복습 추천]              │ [확인 필요]
│ └───────────────────     └───────────────────
│ ┌ 테일러 급수 ───────────
│ │ 아직 시작 전
│ │ [첫 학습 시작하기]
│ └───────────────────
│ [약한 스킬 먼저 보기 ○]
├─ 최근 정리 노트 ──────────────────────────────
│ 9/25 연쇄법칙 정리 · 이해 체크 3/4        [열기 →]
└──────────────────────────────────────────────
```

| 요소 | 설명 |
|---|---|
| 과목 탭 | 과목끼리 합산하지 않고 탭으로 분리 |
| 과목 요약 | 가장 가까운 시험 D-day + 범위, `calibration` 문구 1줄 |
| 오늘 할 일 | P-05 체크리스트 중 오늘 날짜 항목. `[AI]`/`[나]` 출처 태그 |
| AI에서 학습 시작 | 채팅으로 넘어가는 유일한 CTA. 복사되는 문구 예: `StudyMeta로 미적분학 오늘 할 일 시작할래` |
| 스킬 카드 | 상태 문구 1줄 + 배지 최대 2개 (확인 필요 > 도움이 필요해요 > 복습 추천) |
| 최근 정리 노트 | S-01/S-02 결과. 클릭 시 정리 노트 + S-03 근거 화면 |

**예외**
- 과목 0개 → 탭 영역 대신 "과목을 등록하고 계획을 받아보세요 [시작하기]" → P-01
- 시험 일정 없음 → 과목 요약에 "시험 일정을 추가하면 계획을 짜드려요 [추가]"
- 자료 없음 → 스킬 카드 영역에 "자료를 올리면 공부할 개념을 찾아드려요 [업로드]"

## 2. 계획모드

### P-01 과목 등록

```
┌─ 계획 만들기 (1/4) ────────────────────────────
│ 어떤 과목을 준비하나요?
│ 과목명 [ 미적분학                 ]
│ 등록된 과목: 화학 ✕  경제학원론 ✕
│ [+ 과목 추가]
│                               [다음 →]
└──────────────────────────────────────────────
```

- 자유 텍스트 입력, 최소 1과목. 이미 등록된 과목은 칩으로 표시·삭제 가능.

### P-02 시험 일정 · 시험범위

- **목적**: 계획의 기준이 되는 날짜와 범위를 받는다. 범위는 **시험마다** 따로 받는다.

```
┌─ 계획 만들기 (2/4) · 미적분학 ─────────────────
│ 시험 1
│   이름 [ 중간고사 ]   날짜 [ 2026-10-08 ]
│   시험범위
│     ( ) 직접 입력  [ 1~4단원, 교재 p.12~140      ]
│     ( ) 자료에서 고르기  ← P-03 업로드 후 목차 체크
│ [+ 시험 추가]   (퀴즈·기말 등 여러 개 가능)
│
│ [← 이전]                         [다음 →]
└──────────────────────────────────────────────
```

**예외**
- 시험 0개 → 진행은 가능, "날짜 없이 할 일만 만들어요" 안내 (체크리스트에 날짜 배정 없음)
- 범위 미입력 → 업로드 자료 전체를 범위로 간주, 체크리스트 상단에 "범위 확인 필요" 표시

### P-03 자료(PDF) 업로드

```
┌─ 계획 만들기 (3/4) · 미적분학 ─────────────────
│ 강의자료를 올려주세요 (선택)
│ ┌ 여기로 끌어오거나 [파일 선택] ───────────
│ └─────────────────────────────────────
│ 📄 3주차_연쇄법칙.pdf    12p   ✕
│ 📄 교재_4장.pdf         38p   ✕
│
│ [건너뛰기]                        [분석 시작 →]
└──────────────────────────────────────────────
```

- 스킵 가능. 스킵하면 P-02의 범위 텍스트만으로 체크리스트를 만든다.

### P-04 분석 중

```
┌─ 계획 만들기 (4/4) ────────────────────────────
│ 자료를 읽고 할 일을 만들고 있어요
│ 미적분학  ███████████░░░░  목차 찾는 중
│ 화학      ████████████████ 개념 9개 찾았어요 ✓
│ (분석이 끝나면 자동으로 넘어가요)   [나중에 하기]
└──────────────────────────────────────────────
```

**예외**: 분석 실패 → 해당 과목 행에 "다시 시도 / 범위 텍스트로만 만들기"

### P-05 할 일 체크리스트 (계획모드 결과)

- **목적**: 시험범위를 **단원 > 개념** 단위의 할 일로 쪼개고, 날짜에 배치한다.
- **핵심 규칙**: 각 항목은 **출처**와 **판단**을 따로 갖는다.

| 구분 | 값 | 누가 정하나 | 표시 |
|---|---|---|---|
| 출처 | AI 제안 / 내가 추가 | 생성 주체 | `[AI]` `[나]` 태그. AI 항목을 사용자가 수정하면 `[AI·수정됨]` |
| 완료 | ☐ / ☑ | **사용자** | 체크박스. 일정상 "했음"일 뿐 State는 바꾸지 않음 |
| AI 판단 | 확인 필요 / 도움이 필요해요 / 복습 추천 / 없음 | **학습 기록(State)** | 우측 배지. 사용자가 직접 끌 수 없음 |

→ 사용자가 ☑ 했는데 AI 판단이 "확인 필요"면 둘 다 그대로 보여준다(서로 덮어쓰지 않음).

```
┌─ 미적분학 · 중간고사 D-12 ─────────────────────
│ 보기: [목록 ●] [날짜별]          [+ 할 일 추가]
├──────────────────────────────────────────────
│ ▾ 3단원 미분법
│   ☐ 연쇄법칙 개념 이해        [AI]    10/1   복습 추천
│   ☐ 연쇄법칙 문제 풀이        [AI]    10/2
│   ☑ 교재 3장 예제 다시 보기    [나]    9/30
│ ▾ 4단원 적분
│   ☐ 치환적분                 [AI·수정됨] 10/3
│   ☐ 부분적분                 [AI]    10/4   확인 필요
├──────────────────────────────────────────────
│ 범례: [AI] AI가 만든 할 일  [나] 내가 추가한 할 일
│       오른쪽 배지 = 학습 기록을 보고 AI가 판단한 상태
└──────────────────────────────────────────────
```

**날짜별 보기**

```
┌ 오늘 9/30 ──────┬ 10/1 ──────────┬ 10/2 ──────────┬ ···
│ 교재 3장 예제 ☑  │ 연쇄법칙 개념    │ 연쇄법칙 문제    │
│                 │ [◀] [▶]        │ [◀] [▶]        │
└─────────────────┴────────────────┴────────────────┘
  카드는 드래그 또는 ◀▶로 하루씩 이동. 시험일 이후 칸은 잠김.
```

| 동작 | 결과 |
|---|---|
| 항목 탭 | 펼침: 관련 자료 페이지, 최근 학습 기록 한 줄, [이 항목으로 학습 시작 →] |
| 항목 편집/삭제 | AI 항목은 편집 시 `[AI·수정됨]`, 삭제 시 "AI 제안 숨김"(되살리기 가능) |
| 이 항목으로 학습 시작 | 시작 문구 복사 예: `StudyMeta로 미적분학 연쇄법칙 공부 시작할래` |

### P-05′ 채팅에서 체크리스트 열람 ("학습모드 상시 열람")

학습 중 언제든 "계획 보여줘", "오늘 할 일 뭐야?"라고 하면 AI가 MCP로 불러와 텍스트로 보여준다.

```
┌ AI ─────────────────────────────────────────
│ 📋 미적분학 · 중간고사 D-12 · 오늘 할 일
│  ☐ 연쇄법칙 개념 이해   (AI 제안 · 복습 추천)
│  ☑ 교재 3장 예제 다시 보기   (내가 추가)
│ 전체 계획은 웹에서 볼 수 있어요 → [링크]
│ 어떤 것부터 할까요?
└─────────────────────────────────────────────
```

- **MCP**: `get_study_plan` (신규)
- 위젯 지원 시: 체크 가능한 목록 위젯. 미지원 시 위 텍스트 형태.

## 3. 학습모드 (AI 채팅)

### L-01 학습 시작

- **진입**: 홈/체크리스트에서 복사한 시작 문구, 또는 사용자가 직접 "공부 시작할래"
- **MCP**: `get_my_learner_context` (기존) + `get_study_plan` (신규)

```
┌ 나 ──────────────────────────────────────────
│ StudyMeta로 미적분학 오늘 할 일 시작할래
└─────────────────────────────────────────────
┌ AI ─────────────────────────────────────────
│ 좋아요! 미적분학 중간고사까지 12일 남았어요.
│ 오늘 계획된 건 두 가지예요.
│  1. 연쇄법칙 개념 이해 (지난번보다 기억이 흐려졌을 수 있어요)
│  2. 극한의 정의 개념 확인
│ 어디부터 할까요? 번호로 골라도 되고, 다른 범위를 말해도 돼요.
└─────────────────────────────────────────────
```

**예외**
- 계획 없음 → "아직 계획이 없어요. 오늘은 어떤 단원을 볼까요? (웹에서 계획 만들기 [링크])"
- 로그인·연결 안 됨 → MCP OAuth 연결 안내

### L-02 학습 범위 선택

- **단위**: 체크리스트 항목 = **개념** 단위. 단원을 고르면 그 아래 개념을 모두 범위로 잡는다. 여러 개를 고를 수 있다.
- **MCP**: `start_study_session` (신규) — 선택 범위 · 시작 시각 · 연결된 체크리스트 항목 저장

```
┌ 나 ──────────────────────────────────────────
│ 1번이랑 3단원 전체
└─────────────────────────────────────────────
┌ AI ─────────────────────────────────────────
│ 이번 학습 범위
│  • 연쇄법칙 개념 이해
│  • 3단원: 곱의 미분, 몫의 미분, 연쇄법칙
│ 약 30~40분 걸릴 것 같아요. 이대로 시작할까요?
│ (범위는 중간에 "범위 바꿔줘"로 바꿀 수 있어요)
└─────────────────────────────────────────────
```

### L-03 학습 진행

- **목적**: 설명 → 문제 → 피드백을 반복하며, **문제마다 Evidence를 기록**한다.
- **MCP**: `record_learning_event` (기존) — 한 번의 풀이에서 여러 Evidence를 함께 기록
- **원칙**: 원본 대화가 State를 직접 바꾸지 않는다. 대화 → Evidence → State.

```
┌ AI ─────────────────────────────────────────
│ 문제 2. f(x) = sin(3x²) 를 미분해 볼까요?
│ 풀기 전에, 얼마나 자신 있어요?  (1 전혀 ~ 5 확실)
└─────────────────────────────────────────────
┌ 나 ──────────────────────────────────────────
│ 4
│ 6x·cos(3x²)?
└─────────────────────────────────────────────
┌ AI ─────────────────────────────────────────
│ 맞아요! 바깥 함수와 안쪽 함수를 잘 나눴어요.
│ 이번엔 힌트 없이 풀었네요. 다음은 조금 비튼 문제로 가볼까요?
│ ─────────────────────────────────
│ StudyMeta 기록: 정답 · 혼자 힘으로 해결       ← 한 줄 기록 표시
└─────────────────────────────────────────────
```

**채팅 안에서 Evidence를 받는 지점**

| 학생 행동 / AI 질문 | 기록되는 Evidence (학생 라벨) |
|---|---|
| 답 제출 | 정답 / 오답 / 부분적으로 맞음 |
| "힌트 줘" | 힌트 요청 → 이후 풀면 "힌트 받고 해결" |
| "설명해줘" | 설명 듣고 해결 |
| 풀기 전 자신감 질문 (가끔) | 확신 정도 응답 |
| 같은 유형 실수 재발 | 반복되는 실수 / 헷갈리는 개념 후보 |
| 스스로 "아 잘못했다" | 스스로 수정함 / 실수를 스스로 알아챔 |
| 이전 세션 개념을 다시 물음 | 시간이 지나도 기억함 / 시간이 지나 잊어버림 |
| 새로운 형태의 응용 문제 | 새로운 문제에 응용 성공 / 실패 |

- 기록 한 줄은 문제 단위로만 보여주고 매 대화마다 붙이지 않는다.
- 사용자가 언제든 "계획 보여줘"(P-05′), "범위 바꿔줘"(L-02), "그만할래"(L-04)를 말할 수 있다.

### L-04 학습 마무리 감지

- **목적**: 학습이 끝나는 시점을 잡아 정리모드로 넘긴다. **강제하지 않고 제안한다.**

| 감지 신호 | 동작 |
|---|---|
| 사용자가 "끝", "그만할래", "오늘 여기까지" | 바로 정리 제안 |
| 선택 범위의 개념을 모두 한 번 이상 다룸 | 정리 제안 |
| 예상 시간 초과 (예: 선택 범위 예상치 +50%) | "조금 쉬었다 할까요, 정리할까요?" |
| 대화 없이 이탈 | 세션을 "정리 안 됨"으로 저장 → 다음 L-01에서 "지난번 내용 먼저 정리할까요?" |

```
┌ AI ─────────────────────────────────────────
│ 오늘 고른 범위를 다 한 번씩 다뤘어요 👏
│ 잊기 전에 5분만 정리해볼까요?
│   [정리하기]  [조금 더 풀기]  [오늘은 그만]
└─────────────────────────────────────────────
```

- 텍스트 전용 환경에서는 버튼 대신 "정리하기 / 더 풀기 / 그만" 중 하나를 답하도록 안내.
- **MCP**: `end_study_session` (신규) — 종료 시각, 종료 사유(사용자 / 범위 완료 / 시간 / 이탈)

## 4. 정리모드

### S-01 구조화 정리

- **목적**: 이번 세션에서 공부한 내용을 **단원 > 개념 > 핵심 포인트** 위계로 정리한다.
- **소스**: 이번 세션의 대화 + 선택 범위 + 업로드 자료 목차
- **MCP**: `save_session_summary` (신규) — 정리 트리를 저장해 웹 "정리 노트"로 열람

```
┌ AI ─────────────────────────────────────────
│ 📝 오늘 공부한 내용 정리
│
│ 3단원 미분법
│ ├─ 곱의 미분
│ │   └ (fg)' = f'g + fg'
│ ├─ 몫의 미분
│ │   └ 분모 제곱, 순서 주의 (f'g − fg')
│ └─ 연쇄법칙  ★ 오늘 가장 많이 다룸
│     ├ 바깥 함수 미분 × 안쪽 함수 미분
│     └ 안쪽이 또 합성함수면 한 번 더 적용
│
│ 오늘 범위에서 아직 안 다룬 것: 몫의 미분 응용 문제
└─────────────────────────────────────────────
```

| 규칙 | 설명 |
|---|---|
| 개념 트리만 그린다 | 학습 기록과 개념을 선으로 잇는 관계도는 만들지 않는다 |
| 안 다룬 개념 표시 | 선택 범위 중 다루지 않은 개념을 따로 표시 → 체크리스트에 남김 |
| 정답을 새로 가르치지 않음 | 정리는 세션에서 다룬 내용의 요약만. 새 개념 설명은 추가하지 않음 |

### S-02 이해 체크

- **목적**: 사용자가 **스스로** 이해 정도를 표시하게 하고, 그 뒤에 실제 풀이 결과와 비교해 보여준다.
- **순서가 중요**: ① 사용자가 먼저 체크 → ② 그다음에 AI가 본 결과 공개 (AI 판단에 끌려가지 않도록)
- **기록**: 체크 결과는 **"이해했다"는 응답** Evidence로 기록 (`record_learning_event`). State를 직접 바꾸지 않는다.

```
┌ AI ─────────────────────────────────────────
│ 개념마다 지금 느낌을 골라주세요.
│
│                 알겠어요   애매해요   모르겠어요
│ 곱의 미분          ●         ○          ○
│ 몫의 미분          ○         ●          ○
│ 연쇄법칙           ●         ○          ○
│
│ (텍스트로 답할 때: "곱 알겠음, 몫 애매, 연쇄 알겠음")
└─────────────────────────────────────────────
┌ AI ─────────────────────────────────────────
│ 오늘 풀이 결과와 비교해볼게요.
│  • 곱의 미분 — 느낌도, 풀이도 좋았어요 ✓
│  • 몫의 미분 — 애매하다고 했는데, 실제로 순서 실수가 한 번 있었어요.
│                내일 계획에 복습으로 넣어둘게요.
│  • 연쇄법칙 — 알겠다고 했는데, 힌트를 받고 푼 문제가 있었어요.
│                다음엔 힌트 없이 한번 도전해볼까요?
│
│ 자세한 근거는 웹에서 볼 수 있어요 → [근거 보기]
└─────────────────────────────────────────────
```

**정리 결과 → 계획 반영 (순환)**

| 조합 | 체크리스트 반영 |
|---|---|
| 모르겠어요 / 애매해요 | 다음 날에 해당 개념 복습 항목 `[AI]` 추가 |
| 알겠어요 + 실제 풀이도 좋음 | 해당 항목 AI 판단 배지 없음 |
| 알겠어요 + 실제로 힌트·오답 있음 | "확인 필요" 또는 "도움이 필요해요" 배지 |
| 안 다룬 개념 | 체크리스트에 미완료로 남김 |

- **MCP**: `update_study_plan` (신규) — 사용자에게 "내일 계획에 넣어둘게요"라고 말한 것만 반영

### S-03 근거 화면 (State · Evidence · 도움 횟수) — 학생용

- **목적**: "왜 이런 판단이 나왔는지"를 학생이 직접 확인한다.
- **진입**: S-02의 [근거 보기], 홈의 정리 노트, 스킬 카드 상세
- **표면**: 웹 (채팅에는 S-02 비교 문장이 요약본 역할)

```
┌─ 연쇄법칙 · 9/30 학습 근거 ────────────────────
│ [이번 세션 ●] [전체 기록]
├─ ① 지금 상태 ────────────────────────────────
│ 개념 이해        좋아지고 있어요        ↑
│ 풀이 과정        변화 없음              –
│ 기억            잘 기억하고 있어요      ↑
│ 필요한 도움      늘고 있어요           ↓
│ 헷갈리는 부분    없음                  –
│ ▸ 더 보기: 응용력 · 판단 확실도
├─ ② 도움 받은 횟수 (이번 세션) ─────────────────
│ 힌트 요청 2회 · 힌트 받고 해결 1회 · 설명 듣고 해결 1회
│ 혼자 힘으로 해결 3회
├─ ③ 이렇게 판단한 근거 (최근 기록) ──────────────
│ 문제 2  [정답] [혼자 힘으로 해결]
│         → 개념 이해 ↑
│ 문제 4  [오답] [힌트 요청] → [힌트 받고 해결]
│         → 필요한 도움 ↓
│ 이해 체크  ["알겠어요" 응답]  ↔  문제 4 힌트 사용
│         → "예상과 실제가 조금 달랐어요"
└──────────────────────────────────────────────
```

| 영역 | 표시 규칙 |
|---|---|
| ① 지금 상태 | State를 학생 문구 + 방향(↑ ↓ –)으로. 이번 세션에 근거가 없는 State는 **"변화 없음"** (0이나 하락으로 표시하지 않음). 응용력·판단 확실도는 "더 보기" 안에 |
| ② 도움 받은 횟수 | 이번 세션 ASSISTANCE 기록의 **횟수만** 나열. 합산 점수·등급으로 만들지 않음 |
| ③ 근거 | 문제(기록)마다 Evidence 칩 → 영향 준 State를 문장으로. 선으로 잇지 않고 색 강조 + 문장으로 연결 |
| 공통 | 내부 id(snake_case)·원시 수치는 표시하지 않음. 모든 라벨은 학생용 한국어 |

> ⚠️ 초안 메모의 "intervention 숫자"는 위 ②처럼 **도움(힌트·설명)을 받은 횟수**로
> 해석했다. 내부 튜닝 지표인 `intervention_response`(개입 효과 State) 자체는
> 학생 화면에 노출하지 않는다 (`AGENTS.md` 3-2).
