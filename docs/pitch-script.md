# 예상 질문과 답

### Q. ChatGPT가 메모리 기능을 강화하면 끝나는 것 아닌가요?
그 메모리는 한 모델 **안의** 기억이고, 저희는 모델 **사이의** 기록입니다. 학생은 이미 과제는 A, 코딩은 B로 옮겨 다니는데 기억은 옮겨지지 않습니다. 그리고 저희가 저장하는 건 대화 내용이 아니라 스킬 단위로 구조화된 학습 상태입니다.

### Q. AI가 공짜인데 학생이 왜 돈을 냅니까?
학생이 사는 건 답이 아니라 **매번 나를 다시 설명하지 않아도 되는 상태**와 시험까지 남은 날짜에 맞춘 계획입니다. 한 학기 19,900원은 과외 한 시간보다 쌉니다.

### Q. 예측 정확도 70%는 근거가 있습니까?
공개 데이터셋인 ASSISTments와 Eedi로 검증 파이프라인이 이미 돌아가고 있고, 상태 추정이 다음 문제의 정오답을 맞히는지까지 확인했습니다. 70%는 이 파이프라인을 파일럿 30명의 실제 데이터로 보정했을 때의 12주 목표입니다.

### Q. 학습 기록은 민감한 데이터인데 보안은 어떻게 합니까?
모든 테이블에 행 수준 접근 제어를 적용했고, 공개 조회 정책은 두지 않았습니다. 외부에서는 서버를 거친 권한 확인 후에만 읽힙니다. 자금 계획의 제품 개발 35%에 연결 보안·인증이 포함되어 있습니다.

### Q. 대학이 왜 연 1,500만 원을 씁니까?
조교 한 명의 연간 인건비보다 낮은 금액으로 수백 명의 학습 상태를 남깁니다. 대학이 못 보던 "어느 과목 어느 개념에서 학생들이 막히는가"가 데이터로 남는 것이 실제 구매 이유입니다.

### Q. 학생 세 명이 이걸 할 수 있습니까?
이미 했습니다. MCP 서버 배포와 학생 화면 전체 흐름, 검증 파이프라인 두 건이 지금 동작합니다. 남은 12주는 새로 만드는 기간이 아니라 실제 학생으로 맞춰 가는 기간입니다.
