# ADR-001: Academic Navy UI·UX 기본값

- 상태: Accepted for MVP
- 결정일: 2026-09-09
- 적용 대상: 학생 웹, 관리자 웹, MCP/In-chat UI

## 맥락

StudyMeta는 대학생의 외부 AI 학습을 지원하는 Learner Model 관제탑이다. 화면은 친근한 교육 앱보다 신뢰할 수 있는 학습 분석 도구에 가까워야 하지만, 관리자 시스템처럼 차갑거나 복잡해 보여서도 안 된다. 초기 구현 속도를 위해 글꼴, 색, 모서리, 그림자, 아이콘, 모션, 반응형 처리와 말투 기본값을 먼저 고정한다.

참고 방향은 다음과 같다.

- Linear: 절제된 짙은 색, 작은 상태 라벨, 높은 정보 밀도
- Khan Academy: 학생 진행 상태와 활동 기록 탐색
- IBM Carbon: 관리자 데이터 테이블과 점진적 상세 공개
- Atlassian Design System: 필터, 배너, 상태 컴포넌트
- OpenAI MCP UI: 대화 안의 구조화된 정보와 UI 미지원 fallback

## 결정

### 1. 색상 체계

`Academic Navy`를 기본 테마로 사용한다.

| 토큰 | 값 | 용도 |
|---|---:|---|
| `--navy-950` | `#0B1F3A` | 브랜드, 주요 헤더, 관리자 사이드바 |
| `--navy-800` | `#163A63` | 보조 남색, 선택 상태 |
| `--action-blue` | `#3478D4` | 주요 버튼, 링크, 포커스 |
| `--canvas-warm` | `#F7F5F0` | 학생 웹 기본 배경 |
| `--surface` | `#FFFFFF` | 카드와 데이터 영역 |
| `--text-primary` | `#172235` | 본문 |
| `--text-muted` | `#667085` | 보조 설명 |
| `--border` | `#DCE2EA` | 구분선 |
| `--success` | `#0F766E` | 성공·완료 |
| `--warning` | `#B7791F` | 확인 필요·주의 |
| `--danger` | `#B42318` | 실패·무효·오류 |

색만으로 의미를 전달하지 않는다. 아이콘, 텍스트 라벨, 변화 방향을 함께 표시한다.

### 2. 글꼴

외부 CDN을 사용하지 않는다. MVP 기본 스택은 다음과 같다.

```css
font-family: Pretendard, "Noto Sans KR", "Apple SD Gothic Neo",
  "Segoe UI", system-ui, -apple-system, BlinkMacSystemFont, sans-serif;
```

- 설치된 환경에서는 Pretendard를 우선 사용한다.
- 폰트가 없어도 시스템 글꼴로 기능과 레이아웃이 유지되어야 한다.
- 실서비스에서 Pretendard를 보장해야 한다면 CDN이 아니라 라이선스를 확인한 self-hosted WOFF2를 사용한다.
- 숫자·버전·시간에는 tabular numerals를 사용한다.

### 3. 모서리

| 요소 | radius |
|---|---:|
| 기본 카드 | `16px` |
| MCP 카드 | `16px` |
| 모달·Drawer | `18px` |
| 버튼·입력 | `10px` |
| 작은 내부 패널 | `12px` |
| 상태 칩 | `999px` |

장식적인 과대 라운딩을 피하고, 표와 감사 로그 영역은 카드보다 각을 조금 더 유지한다.

### 4. 그림자

기본 카드 그림자는 다음 한 단계만 사용한다.

```css
box-shadow: 0 8px 24px rgba(11, 31, 58, 0.08);
```

- 테이블 내부 행에는 그림자를 사용하지 않는다.
- hover에서는 위치를 크게 움직이지 않고 테두리 또는 배경만 바꾼다.
- 모달은 `0 20px 60px rgba(11, 31, 58, 0.16)`까지 허용한다.

### 5. 아이콘

- 1.75~2px 굵기의 단색 outline 아이콘을 사용한다.
- Lucide 계열의 시각 문법을 참고하되, 외부 런타임 의존성을 피하기 위해 필요한 아이콘만 inline SVG로 포함한다.
- 이모지는 상태·탐색·조작 아이콘으로 사용하지 않는다.
- 아이콘 단독 버튼에는 접근 가능한 이름을 제공한다.

### 6. 테마

- 학생 웹과 관리자 웹 MVP는 밝은 `Academic Navy` 테마를 기본으로 한다.
- 관리자 웹은 남색 사이드바와 밝은 데이터 본문을 사용한다.
- MCP/In-chat UI는 호스트의 light/dark 색상 선호를 감지해 두 테마를 지원한다.
- 학생·관리자 웹의 수동 다크 모드 토글은 MVP 이후로 미룬다.

### 7. 모션

- 버튼·상태 변화: `160ms`
- 카드 펼침·Drawer: `220ms`
- easing: `cubic-bezier(0.2, 0, 0, 1)`
- bounce, 자동 반복, 과도한 slide 효과는 사용하지 않는다.
- `prefers-reduced-motion: reduce`에서는 비필수 모션을 제거한다.

W3C는 상호작용 애니메이션에 `prefers-reduced-motion`을 적용해 사용자의 시스템 설정을 존중하는 방식을 안내한다: <https://www.w3.org/WAI/WCAG21/Techniques/css/C39.html>.

### 8. 말투 선택

첫 버전부터 다음 세 preset을 데이터 계약에 포함한다.

| ID | 학생 표시 | 성격 |
|---|---|---|
| `concise` | 간결한 안내 | 핵심 정보와 다음 행동만 제공 |
| `calm_coach` | 차분한 학습 코치 | 기본값. 명확하고 정중하며 과도한 구어체를 피함 |
| `supportive` | 격려 중심 | 절제된 격려를 추가하되 감탄사와 과장 금지 |

선택 UI는 학생 설정과 세션 시작 카드에서 제공한다. 이 값은 표현과 설명 길이에만 영향을 주며 Evidence 분류, State 계산, 과학적 검증 상태에는 영향을 주지 않는다.

기본 문구 예:

> 이전 학습 내용을 불러왔습니다. 연쇄법칙 학습을 이어서 진행할 수 있습니다.

### 9. 모바일 표

- `767px` 이하에서는 학생·관리자 테이블을 세로 카드 목록으로 전환한다.
- 가로 스크롤을 기본 해결책으로 사용하지 않는다.
- 필터는 상단 Drawer로 모은다.
- 카드에는 핵심 4~6개 필드만 표시하고 나머지는 펼쳐 본다.
- 데스크톱에서는 Carbon 방식의 정렬·필터·확장 행을 사용한다.

### 10. Session Summary 구조도

- 서술문 중심 결과가 아니라 `세션 정보 → 활동 → Evidence → State 결과 → 다음 행동` 구조로 표시한다.
- 연결선 색은 `--border`, Learning Event 노드는 파랑, Evidence 노드는 주황, State 노드는 남색을 사용한다.
- 상승/하락을 색만으로 표현하지 않는다. `상승`, `하락`, `유지`, `판단 보류` 문구를 함께 쓴다.
- `help_need`처럼 감소가 긍정적인 State가 있으므로 초록=상승, 빨강=하락의 전역 규칙을 사용하지 않는다.

## 선택 이유

- 짙은 남색은 신뢰성과 학술적 인상을 만들고, 밝은 본문은 장시간 읽기와 ChatGPT 안의 카드 대비에 유리하다.
- 시스템 글꼴 fallback은 외부 네트워크와 렌더링 지연에 대한 의존을 줄인다.
- 작은 모션과 제한된 그림자는 전문적인 정보 제품의 인상을 유지한다.
- 모바일 카드 전환은 복잡한 표의 가로 스크롤과 작은 터치 대상을 피한다.
- 말투 preset을 State 계산과 분리하면 개인화는 제공하면서 모델의 과학적 판단을 오염시키지 않는다.

## 결과와 제약

- 첫 시안은 모든 세부 장식을 다시 선택하지 않고 일관된 토큰으로 제작할 수 있다.
- MCP UI는 호스트 테마 호환을 위해 웹보다 한 단계 더 많은 테마 검증이 필요하다.
- self-hosted Pretendard 도입 여부는 번들 크기 측정 후 재검토한다.

## 재검토 조건

- 학생 5명 이상의 사용성 테스트에서 정보 밀도나 가독성 문제가 반복될 때
- MCP 호스트의 테마 API가 변경될 때
- 폰트 로딩이 핵심 렌더링 지연의 원인으로 측정될 때
