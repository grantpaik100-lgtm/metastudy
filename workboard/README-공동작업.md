# 작업판 실시간 공동 작업

여러 사람이 같은 작업판을 동시에 편집합니다. 한 사람이 화면을 추가하거나 고치거나 카드를 옮기면 다른 사람 화면에도 곧바로 보입니다.

## 구조

- 서버를 켠 사람의 Mac(이 폴더)이 작업판 원본을 가지고 있습니다. 저장 위치는 `data/board.json`입니다.
- 팀원은 ngrok 주소로 들어옵니다. 주소를 아는 사람은 **누구나 보고 편집할 수 있습니다.**
- 서버가 꺼지거나 Mac이 잠자기 상태가 되면 아무도 접속할 수 없습니다.

## 시작하기 (서버를 켜는 사람)

1. 터미널 창 1에서 다음을 실행합니다. 이 창은 계속 열어 둡니다.
   ```bash
   cd ~/Downloads/"workboard-template 2"
   npm run dev
   ```
2. 브라우저에서 `http://127.0.0.1:4173`을 엽니다.
   - 예전에 이 브라우저에서 쓰던 작업판이 있으면 "공동 작업판으로 올릴까요?"라고 한 번 묻습니다. **확인**을 누르면 됩니다.
3. 터미널 창 2에서 다음을 실행합니다.
   ```bash
   ngrok http 4173
   ```
4. 창 2에 나온 `https://….ngrok-free.app` 주소를 팀원에게 보냅니다.

## 팀원

- 받은 주소를 엽니다. ngrok 안내 화면이 나오면 **Visit Site**를 누릅니다.
- 처음 들어오면 이름을 묻습니다. 이 이름으로 다른 사람에게 "○○ 편집 중" 같은 표시가 보입니다.

## 동시에 편집할 때 규칙

- 같은 화면의 **다른 칸**을 동시에 고치면 둘 다 반영됩니다.
- 같은 칸을 동시에 고치면 **마지막에 저장한 사람**의 내용이 남습니다. 누가 편집 중인지 카드에 이름표가 붙으니 확인하고 고치세요.
- 편집 창을 연 동안 다른 사람이 그 항목을 고치면 편집 창 위에 알림이 뜹니다.
- **불러오기**는 모든 사람의 작업판을 통째로 바꿉니다. 바꾸기 직전 상태는 자동으로 백업됩니다.

## 끄기

- ngrok 창에서 `Ctrl+C`를 누르면 외부 접속이 바로 끊깁니다.
- 서버 창에서 `Ctrl+C`를 누르면 저장과 백업을 한 뒤 종료합니다.
- 다시 `ngrok http 4173`을 실행하면 주소가 바뀔 수 있습니다. 새 주소를 다시 보내야 합니다.

## 백업과 복구

- `data/backups/`에 자동 백업이 쌓입니다(최근 50개). 서버를 시작할 때, 5분마다(변경이 있을 때), 불러오기 직전, 종료할 때 만들어집니다.
- `data/changes.log`에는 누가 언제 무엇을 바꿨는지 기록됩니다.
- 복구하는 방법:
  - 서버를 켠 채로: 작업판의 **불러오기**에서 백업 파일을 선택합니다.
  - 서버를 끈 상태에서: 다음을 실행합니다.
    ```bash
    npm run dev -- --seed data/backups/<백업파일>.json
    ```

## AI와 함께 쓸 때

`data/board.json`을 서버가 켜진 상태에서 직접 고치면 서버가 덮어씁니다. AI가 만든 JSON은 **불러오기**로 반영하세요.

## 보안

- 서버는 이 Mac 안(`127.0.0.1`)에서만 접속을 받습니다. 외부 사람은 ngrok을 거쳐야만 들어옵니다.
- 외부로 제공하는 파일은 이 폴더 바로 아래의 화면 파일(`.html`, `.js`, `.css`, 이미지, 폰트)뿐입니다. `data/`, `.env`, `.git`, `server.mjs`, `package.json`, `.md`, `.json` 파일은 제공하지 않습니다.
- 주소를 아는 사람은 누구나 편집하고 삭제할 수 있습니다. 주소는 팀원에게만 보내고, 작업이 끝나면 ngrok을 끄세요.

## 바뀐 파일

| 파일 | 내용 |
|---|---|
| `server.mjs` | 새로 작성. 공동 작업 서버(실시간 전달, 저장, 백업, 변경 기록) |
| `board-ops.js` | 새 파일. 작업판 변경 규칙. 브라우저와 서버가 함께 씀 |
| `app.js` | 브라우저 저장 대신 서버로 변경을 주고받음. 접속자·편집 중 표시 추가 |
| `collab.css` | 새 파일. 접속자·편집 중 표시 스타일 (`styles.css`는 그대로) |
| `index.html` | `collab.css` 연결, 상단에 접속자 자리 추가 |

바꾸기 전 원본은 `backup-before-realtime/`에 있습니다.
