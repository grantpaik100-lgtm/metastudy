# UI 작업판 템플릿

> **현재 사용 안내:** [클라우드 공동 작업·로그인·MCP](./CLOUD-GUIDE.md), [네 상세 공간과 실제 3D 면](./STRUCTURE-GUIDE.md), [회의·채팅·녹음 안내](./MEETINGS-GUIDE.md)를 먼저 읽으세요. 로컬 서버 실행은 [SPATIAL-GUIDE.md](./SPATIAL-GUIDE.md)를 참고하세요.
> 아래는 원본 ZIP의 이전 설명입니다. 현재 작업판은 공유 DB와 로그인·MCP, 기획/UI/MCP/백엔드 상세 공간을 제공합니다.

루미아 작업실의 **구조와 사용 흐름**을 참고한 독립형 빈 작업판입니다. 루미아 화면, 데이터, API, 계정, 환경변수는 포함하지 않습니다.

작업판을 브라우저 한쪽에, Codex나 Claude 같은 AI 작업 도구를 다른 쪽에 두고 함께 작업하는 운영 방식은 [AI_SIDE_BY_SIDE_WORKFLOW.md](./AI_SIDE_BY_SIDE_WORKFLOW.md)를 먼저 읽어 주세요.

여러 화면에 영향을 주는 중요한 결정과 그 이유는 [DECISIONS.md](./DECISIONS.md)에 기록합니다.

처음 사용하는 사람은 [AI_GUIDED_PRACTICE.md](./AI_GUIDED_PRACTICE.md)를 AI에게 건네고 “내가 방향을 말하면 네가 작업판을 작성하는 방식으로, 작은 예시 프로젝트를 같이 만들어 줘”라고 요청하면 됩니다.

## 실행

Node.js 20 이상에서 이 폴더를 열고 `npm run dev`를 실행한 다음 `http://127.0.0.1:4173`에 접속합니다. 패키지 설치는 필요 없습니다.

## 네 공간

| 공간 | 할 일 |
| --- | --- |
| 실험실 | 독립적인 UI 가설과 시안의 목적, 상태, 참고 URL 기록 |
| 와이어프레임 | 화면 목록과 각 화면의 목적, 구성 블록 정리 |
| 흐름도 | 와이어프레임 화면을 연결하고 화면 카드를 드래그해 배치 |
| 목업·프로토타입 | 같은 화면을 폰 프레임에서 클릭하며 흐름 확인. 화면 URL이 있으면 실제 페이지를 임베드 |

홈에서 프로젝트 이름을 바꾼 뒤 화면을 추가하면 와이어프레임·흐름도·프로토타입에 함께 나타납니다. 흐름도에서 화면 사이를 연결하면 프로토타입의 이동 버튼이 만들어집니다. 실험실 기록은 화면 목록과 독립적입니다.

작업 내용은 **현재 브라우저의 로컬 저장소**에 저장됩니다. 팀원에게 현재 내용을 넘길 때는 상단의 **내보내기**로 JSON 파일을 저장하고, 상대는 **불러오기**를 사용합니다. 빈 템플릿만 전달하려면 이 폴더 자체를 복사하면 됩니다. 배포나 서버 동기화 기능은 없습니다.

## AI와 데이터를 주고받기

작업판 자체에 AI 계정이나 API 연결은 없습니다. 평소 사용하는 AI 대화 도구와 JSON 파일로 주고받습니다. 전체 작업 방식과 공간별 요청 예시는 [AI_SIDE_BY_SIDE_WORKFLOW.md](./AI_SIDE_BY_SIDE_WORKFLOW.md)에 있습니다.

1. 상단 **AI와 함께**를 눌러 홈의 안내로 이동합니다.
2. **AI 요청문 복사**를 눌러 현재 작업판의 JSON과 입력 형식을 복사합니다. 프로젝트 목표와 이번에 원하는 작업을 적어 AI 대화에 붙여 넣습니다.
3. AI가 반환한 **JSON 객체 전체**를 `workboard-project.json`으로 저장합니다. 상단 **불러오기**로 반영하기 전에 현재 상태를 **내보내기**로 백업합니다.
4. 와이어프레임에서 내용, 흐름도에서 연결, 프로토타입에서 이동을 확인합니다. 맞지 않는 제안은 직접 고치거나 JSON을 다시 AI에게 건네 수정 요청합니다.

AI에게 작업판 **디자인이나 기능 자체**를 고치게 하려면 이 폴더를 AI 코딩 도구에서 열고 `README.md`, `index.html`, `styles.css`, `app.js`를 함께 읽도록 요청하세요. 브라우저에 저장된 화면 내용은 파일에 들어 있지 않으므로 먼저 JSON을 내보내야 합니다.

예시 요청: “이 작업판을 우리 서비스의 신규 사용자 흐름에 맞춰 채워줘. 핵심 화면 5개를 추가하고, 첫 방문 경로를 연결해줘. 기존 화면과 ID는 유지하고 가져오기 가능한 JSON만 반환해줘.”

## 파일

- `index.html` — 앱 껍데기와 편집 대화상자
- `styles.css` — 공통 디자인과 반응형 배치
- `app.js` — 네 공간, 편집 기능, 로컬 저장, JSON 가져오기·내보내기
- `server.mjs` — 로컬 실행용 정적 서버
- `AI_SIDE_BY_SIDE_WORKFLOW.md` — 작업판과 AI를 나란히 사용하는 실제 운영 방식
- `AI_GUIDED_PRACTICE.md` — AI가 한 단계씩 진행하는 20~30분 미니 실습
- `DECISIONS.md` — AI와 팀원이 공유하는 가벼운 결정 장부

템플릿을 다른 프로젝트에 옮긴 뒤 색상은 `styles.css` 상단의 CSS 변수에서 변경할 수 있습니다.
